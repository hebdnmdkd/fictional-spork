# Вместе — YouTube watch party

Небольшой сайт для совместного просмотра YouTube: общая комната по ссылке, синхронизация play/pause/перемотки и четыре быстрые реакции — какашка, деньги, инфузория-туфелька и роза.

## Запуск

Нужен Node.js 18+; сторонние npm-пакеты не требуются.

```bash
node server.js
```

Затем откройте `http://localhost:3000`. Нажмите «Пригласить друга» и отправьте ссылку: участники, открывшие одну и ту же ссылку, попадут в общую комнату.

## Как работает синхронизация

Состояние комнаты передаётся сервером браузерам через Server-Sent Events, а команды (воспроизведение, пауза, перемотка и реакции) отправляются обычными HTTP-запросами. Это даёт быструю синхронизацию без периодического опроса сервера; фактическая задержка зависит от сети и ограничений/буферизации YouTube. Для воспроизведения нужен доступ к YouTube и разрешённое встраивание конкретного видео.

Комнаты хранятся в памяти работающего Node-процесса и сбрасываются при его остановке. Для публичного размещения нужен Node-хостинг с HTTPS и, если нужна сохранность комнат после перезапуска, внешнее хранилище.

## Публикация на Render

В корне есть `render.yaml` и `package.json` для Node Web Service. После добавления проекта в GitHub можно создать в Render новый Blueprint и выбрать этот репозиторий. Render возьмёт настройки запуска из `render.yaml`; после публикации появится публичный HTTPS-адрес. На Surge одной публикации недостаточно: там нужен отдельный хостинг для Node-сервера.
